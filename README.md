# 🌾 AgriSmart-AI

**Climate-Smart Agriculture Platform for Nashik Farmers**

A comprehensive platform specialized for the Nashik agricultural belt, empowering farmers with AI-driven price intelligence, weather insights, and market access for Grapes, Onions, and Tomatoes.

---

## 🎯 Vision

To bridge the gap between traditional agricultural wisdom and cutting-edge technology, providing precision guidance to smallholder and commercial farmers in the semi-arid Maharashtra region through real-time market intelligence and climate-smart advisory.

---

## ✨ Core Features

### 📊 Price Intelligence Dashboard
- Real-time prices across 500+ markets
- 7-day ML-based price predictions
- Historical price trends and seasonal patterns
- Optimal selling time recommendations
- Regional language support (Marathi/Hindi/English)

### 🌦️ Climate-Smart Advisory
- Real-time weather forecasts and alerts
- Frost, pest, and disease warnings
- Precision irrigation scheduling
- Crop-stage-specific recommendations
- SMS/Voice alerts for critical updates

### 🤝 Direct Market Linkage
- Buyer-farmer connection platform
- Quality-based transparent pricing
- Bulk order posting system
- Reduced middlemen dependency (70% reduction)

### 📅 Crop Calendar
- Growth stage tracking (Seedling → Harvest)
- Task recommendations (irrigation, fertilizer, pest control)
- Expected harvest predictions
- Weather-integrated scheduling

### 🔔 Smart Alert System
- Push notifications for price changes
- Weather warning alerts
- Customizable quiet hours
- Multi-channel delivery (SMS/Push/Voice)

## 🚀 Getting Started

### Prerequisites
- Node.js 18.x or higher
- npm 11.x or higher

### Installation

1. Clone the repository
```bash
git clone https://github.com/bhaveshpatil093/AgriSmart-AI.git
cd AgriSmart-AI
```

2. Install dependencies
```bash
npm install
```

3. Create `.env` file (optional for development)
```env
VITE_SUPABASE_URL=your_supabase_url
VITE_SUPABASE_ANON_KEY=your_supabase_key
```

4. Start development server
```bash
npm run dev
```

5. Build for production
```bash
npm run build
```
